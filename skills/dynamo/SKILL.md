# /dynamo

Usage: `/dynamo بدي أطلق منتجي خلال أسبوعين` (any language, any wording).

1. Delegate to the `dynamo` agent (`Agent(subagent_type="dynamo")`) with the person's words, or follow the `dynamo-run`
   skill yourself step by step: intake → programme table (ask for a yes) → waves of specialists in parallel → gate
   messages (ready · decisions · blocked) → one consolidated result through `mudawwin`.
2. Before the first run in a venture, make sure the Flow OS connection exists (the `onestudio` MCP, linked with
   `/venture-link`), so intake can read the venture. Without it, intake works from the repo, the live site and what the
   person pastes, and says so.
3. Never publish, send, spend or merge; route those to the reviewer's yes.
