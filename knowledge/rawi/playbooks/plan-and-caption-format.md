## Plan file (what the PDF builder and nashir read)
```
# <Venture>: خطة محتوى <الفترة>

## 1. الأحد 22 نوفمبر: <العنوان>
**الشكل:** بوست + ستوري + لينكدإن   **المحور:** الكشف
**السطر على الصورة:** <جملة واحدة>
**الكابشن**
<hook line with keyword>

<one numbered practical point or 3 short lines>

<close: comment / save ask>
#tag1 #tag2 #tag3 #tag4
---
```
One `## n. <day>: <title>` per post; the `**الكابشن**` block is exactly what gets published; `---` ends the post.
Carousels add `**الشرائح:**` with one line per slide. Polls add `**السؤال:**` and `**الخيارات:**`.

## Caption template (all platforms, one text)
1. **Hook ≤125 characters**, keyword inside, no emoji, ends with a full stop or a question mark.
2. **Body:** one numbered practical point (or a 3-line list), concrete nouns, the segment's own words. 3–6 short lines.
3. **Evidence:** a named source in the body when a claim needs one ("حسب توقّع Gartner…").
4. **Close:** one ask (comment with X / save this / tell us Y).
5. **Hashtags:** 3–5, one line, brand tag last. No hashtag inside sentences.
6. **Link:** never inside the caption; "الرابط في البايو" or first comment.
Length: 600–1,200 characters for feed posts; LinkedIn tolerates longer but the same text is used.

## Bio and About limits (checked 2026-11-19)
Instagram bio 150 chars · Facebook short description 255 · LinkedIn tagline 120 · LinkedIn About 2,000 · X bio 160.
Pattern: what it does (one line) · for whom only if the profile allows · hook line · CTA line. Bilingual About: Arabic
block first, English second, same facts, the brand line closing both.

## Publishing-sequence edits
When a plan moves to daily posting: "tomorrow" posts say «بكرة», follow-ups say «أمس», multi-part says «(2/3)».
Panoramas: right tile first, then centre, then left, so the grid reads right-to-left as one image.
