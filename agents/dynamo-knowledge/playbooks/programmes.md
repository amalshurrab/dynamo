# Programme shapes

Source: the Mathkor launch programme (17–19 Nov 2026) and the team's division of labour in TEAM.md. last_verified: 2026-11-19

Every programme starts with **Wave 0: intake** (mukhattit or the lead; output `marketing/venture-profile.md`; gate: the
owner confirms the profile) and ends with **Wave Z: report** (mudawwin; output the PDF + Flow OS update; gate: the
reviewer's yes before posting).

## 1. Launch from zero (no name, identity or accounts)
| Wave | Specialists (parallel ∥) | Output | Gate |
|---|---|---|---|
| 1 | mukhattit | segment matrix, first channel, 90-day plan | choose segment + channel |
| 2 | wassam | name rounds with domain + registry checks | choose the name; owner reserves domain + handles |
| 3 | naqqash | two identity directions as real screens | choose direction; then full system |
| 4 | rawi ∥ muharrir | month plan + captions ∥ site copy file | approve voice (two samples first), approve copy |
| 5 | lawwan ∥ bannaa ∥ maher | designs in 3 sizes ∥ landing page/code ∥ SSR, mail, DNS | approve designs; developer applies code |
| 6 | mudaqqiq | launch-readiness audit P0/P1/P2 | P0 cleared |
| 7 | nashir ∥ safeer ∥ (mulin) | schedule the month ∥ start outreach ∥ (ads plan only) | yes per artefact; written yes on any spend |

## 2. Content month (brand exists)
Waves: 0 intake → 1 rawi (plan + two voices) → gate → 2 rawi (all captions) ∥ lawwan (two treatments of post 1) → gate →
3 lawwan (all designs, grid, PDF) → gate → 4 nashir (schedule + verification) → Z.

## 3. Site readiness (site exists, customers coming)
Waves: 0 → 1 mudaqqiq (audit) ∥ muharrir (copy compare) → gate (priorities, owners) → 2 bannaa ∥ maher (handoff code) →
3 mudaqqiq (re-audit after deploy) → Z.

## 4. Segment discovery (which customer first)
Waves: 0 → 1 mukhattit (matrix, hypotheses, interview design) → gate → 2 safeer (lists, messages, interviews, free
audits) with weekly pipeline → 3 mukhattit (decision memo, stage-rule proofs) → Z.

## 5. Paid push (tracking exists)
Waves: 0 → 1 mudaqqiq (tracking readiness) ∥ mulin (two plans) → gate (plan + budget, written) → 2 rawi ∥ lawwan (ad
copy and creatives) → gate → 3 mulin (set-up, read-back verification) → weekly loop → Z.

## Rules for every programme
- A wave's brief carries: the profile, the exact ask, earlier outputs, the applicable rules, and "done" criteria.
- Two options first at every creative gate; one recommendation from the lead.
- A gate message is one message: ready · decisions (numbered, with recommendation) · blocked.
