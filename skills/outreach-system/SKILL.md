# outreach-system

## 1. Prospect sheet (`marketing/outreach/pipeline.csv` or the owner's sheet)
Columns: `segment, company, person, role, channel, contact, source, consent_basis, priority, owner, stage, stage_date,
next_action, next_date, variant, notes`. Stages: listed → contacted → replied → interviewed | audit_accepted →
audit_delivered → trial → paying · lost(reason) · opted_out. Sources per segment are named in the sheet; de-duplicate by
person then company. Share before writing messages.

## 2. First touch, two variants (per segment × channel)
≤ 60 words. Structure: one observed fact about them · the problem in their words · one easy question. No link on
LinkedIn first touch; one link on email. A = problem-led, B = proof-led (a real number from the venture profile's allowed
evidence, with source). Set the reply-rate threshold before sending. Check against the profile's banned words and
register; rawi reviews voice.

## 3. Ladder and daily plan
Day 0 touch · day 3 short add · day 7 offer (free audit / 15-min call) · day 14 polite close. Each morning produce
"today's list": rows due, approved text per row, channel. Caps: ~100 LinkedIn invitations/week, ~20 cold messages/day,
WhatsApp Business only to warm or opted-in contacts; one channel per person per day; buyer's working hours; no Friday in
the Gulf.

## 4. Interview script (5 per segment, ~20 minutes)
1. شو تعملون اليوم بخصوص <X>؟ 2. آخر مرة عملتوها، إيمتى وكيف؟ 3. شو كلّفكم وقت أو فلوس؟ 4. شو جرّبتوا وتركتوا، وليش؟
5. مين غيرك بيقرّر؟ Then: ممكن أقتبس كلامك بدون اسم؟ No pitching; no "would you buy". Evidence note the same day:
facts · quotes (with consent) · surprises · what changes for the segment score.

## 5. Free audit / pilot flow
Ask → confirm input (URL) → task to muharrir/mudaqqiq with a date ≤ 5 working days → 15-minute presentation with the owner
→ next step in the profile's offer wording → log outcome and reason.

## 6. Weekly pipeline report (formal MSA)
```
الأسبوع <n> · <from–to>
| الشريحة | مُدرَج | تم التواصل | ردّ | مقابلة | فحص مقبول | فحص مُسلَّم | تجربة | يدفع | خسارة |
نسبة الرد: النسخة أ <x%> · النسخة ب <y%> · القناة الأفضل: <…>
المقابلات: <done>/<target> · الفحوصات: <accepted>/<offered>
أفضل ثلاث خطوات للأسبوع القادم: 1 … 2 … 3 …
```
Numbers come from the sheet, never estimated. Hand to mudawwin.

## Gates
Approval of the exact text per person or list before any send. Opt-outs honoured and logged at once. Business contacts
only, with source and lawful basis. No passwords, no automation tools on the owner's account.
